# Tether 0.1.1 — first public release

Tether by Spacie provides attended remote terminal debugging for developers and AI agents.

- One Tauri desktop app serves as host and operator.
- Interactive native PTY with terminal resizing and UTF-8 output.
- Temporary TryCloudflare HTTPS/WSS routing with a bundled, pinned, checksum-verified sidecar.
- Local approval, one-use invitations, timed sessions, revocation, and audit metadata.
- Built-in stdio MCP server with seven tools and a copy-paste configuration/prompt.
- Node CLI and authenticated async command jobs with cancellation, output bounds, timeouts, and exit codes.
- Cross-platform checks, protected main branch, and automated release builds.
- Redesigned workspace with session progress, clearer host/operator controls, persistent forms/terminal tabs, and responsive navigation.
- Manual update checks, release notes, signed package downloads, progress, and installation guarded against active sessions.
- Updated TypeScript, Vite, React plugin, xterm, Rust dependencies, and pinned workflow actions together.

Download the Windows x64 `.exe`, macOS Apple Silicon/Intel `.dmg`, or Linux x64 `.deb` / `.AppImage`. The `SHA256SUMS-<platform>.txt` files contain checksums for the corresponding installers. All four targets pass the shared checks and packaged MCP test before release publication.

Update packages are signed with Spacie's updater key. Windows publisher signing and Apple notarization are not configured, so installers may show operating-system prompts. Linux updates preserve the installed AppImage or Debian format; Debian installation can require administrator authentication. Open Settings to check for updates and choose when to install.

Screen sharing, mouse control, unattended access, and elevation are outside this release. Approved commands inherit the host account's permissions; the starting folder is not a sandbox. Cloudflare terminates TLS, so this version does not provide end-to-end encryption against the relay.

Read the [setup guide](https://github.com/abdvlrqhman/Tether#readme), [MCP instructions](https://github.com/abdvlrqhman/Tether/blob/main/docs/MCP.md), and [security model](https://github.com/abdvlrqhman/Tether/blob/main/SECURITY.md).
